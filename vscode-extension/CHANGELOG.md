# Changelog

Todas as mudanças notáveis deste projeto serão documentadas neste arquivo.

## [1.1.1] - 2025-10-11

### Adicionado
- ✨ **Suporte para funções**: Palavra-chave `funcao` e `retorna` na syntax highlighting
- 📝 **4 Novos snippets**: `funcao`, `funcaoret`, `chamar`, `retorna`
- 🔧 **Interpretador**: Implementação completa de funções personalizadas
- 📚 **Exemplos**: Arquivo `funcao.aprende` e `exemplo-funcoes-simples.aprende`

### Melhorado
- 🎨 **Syntax highlighting**: `funcao` e `retorna` destacadas como palavras-chave de controle
- 💡 **IntelliSense**: Sugestões para comandos de função
- 📖 **Documentação**: Exemplos práticos de uso de funções
