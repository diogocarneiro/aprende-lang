## 📐 Recomendações para Screenshots

### Formato e Qualidade:
- **Formato**: PNG para capturas de tela (melhor qualidade)
- **Resolução**: Mínimo 1920x1080 para clareza
- **Compressão**: Otimizar para web mas manter legibilidade

### Conteúdo:
- **Código limpo**: Exemplos bem formatados e comentados
- **Interface clara**: UI elements bem visíveis
- **Contexto**: Mostrar resultado e processo completo
- **Anotações**: Adicionar setas ou highlights quando necessário

### Nomenclatura:
```
calculadora-menu-principal.png
calculadora-operacao-soma.png
vscode-syntax-highlighting.png
vscode-go-to-definition.png
instalacao-passo-1.png

```
